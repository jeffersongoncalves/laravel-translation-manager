# TranslationManager

Database overrides for Laravel translations: edit any key - app, JSON or vendor package - at runtime, find missing translations per locale and export the result back to lang files.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/laravel-translation-manager
```
